# LearnFlow AI | 2-minute Demo Recording Guide

**Record only what works in the current deployed build.** If the tutor is not responding, do not pretend an AI answer was generated.

| Time | Show | Suggested narration |
|---|---|---|
| 00:00–00:15 | Landing page | “LearnFlow turns passive lecture watching into interactive learning.” |
| 00:15–00:35 | Enter educational YouTube link | “Students can load a lecture directly into the learning workspace.” |
| 00:35–00:55 | Video + transcript | “The application retrieves timestamped captions to provide lecture context.” |
| 00:55–01:30 | Ask a real question **if fixed** | “The tutor uses lecture context to explain concepts and point back to relevant moments.” |
| 01:30–01:50 | Show real timestamp/citation **if verified** | “Students can revisit the exact moment in the lecture.” |
| 01:50–02:00 | Closing shot | “LearnFlow makes lectures easier to follow, question, and revisit.” |

## Recording and sharing

- Use Windows screen recording (`Win + Shift + R`) or another screen recorder.
- Keep browser zoom readable; hide API keys and private browser tabs.
- Export MP4 and upload to Google Drive or YouTube (unlisted).
- Set sharing so judges can view without requesting access.
- Open the shared link in an incognito window to confirm access.

If the tutor remains broken, record the functioning parts and state the limitation honestly; a nonworking AI answer should not be staged.
